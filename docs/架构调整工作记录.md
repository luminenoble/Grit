# 架构调整工作记录

依据：[修改文档.md](修改文档.md)。实施日期：2026-10-08。

## 本次范围

完成 Category → Task → Section 数据架构、Task 编辑、新格式备份和旧功能清理。固定米色基础主题作用于现有 Task、Setting 和任务小组件。

Rhine 只保留导航入口及启动页枚举，页面当前仅显示名称。本次不实现 Rhine 场景、投影、0 号块交互、手势、起伏、层级动画、搜索定位或显示参数 UI。仓库中的计数、摘要、分页及位置移动接口属于业务架构，供后续界面调用。

## 已实施内容

### 数据与事务

- Category 增加描述、独立文字颜色、创建/修改时间；Task 增加独立文字颜色、记录时间，保留今天、手动完成和提醒。
- Section 使用独立表，持久化 ID、taskId、title、content、orderIndex、completedOn 和记录时间。标题默认为 `unname`，同日允许多条记录。
- 完成状态由完成日期推导，取消完成清空日期，未来日期在编辑器和数据层均拒绝；完成 Section 不自动完成 Task。
- 新库文件名为 `grit_rhine_database`，schema 版本为 1。旧 Task/Habit 数据库文件不读取、不迁移、不删除。
- 批量删除在单次事务中执行后统一刷新；连续排序请求串行提交，避免保存状态丢弃后续位置。
- 数据库外键级联删除；新增只尾插；移动和删除时在事务内补齐同级 orderIndex，显示序号与固定 ID 分离。
- 整页 Task 草稿在同一事务中合并 Section 的新增、修改、删除和排序；已有 Section ID 不因任务归属变化或排序而改变。
- 提供类别流、Task/Section 范围摘要、父级计数、标题搜索、按目标位置移动及一致快照接口，摘要不加载正文。

### Task 编辑

- Category 编辑增加描述及可选文字颜色；Task 文字颜色独立，可恢复默认深灰。
- Section 左侧显示独立序号，标题超长滚动；完成日期可补记。
- 任务详情增加独立排序切换按钮，右侧按模式显示编辑或拖动操作，支持输入目标序号。
- 草稿以打开时的数据快照判断修改，避免新建任务重新渲染的时间字段导致误报。返回存在未保存内容时提示保存或放弃。数据提交成功后返回，保存失败保留草稿并提示错误；保存中禁止重复提交。
- 保留手动完成、今天视图和任务提醒；任务完成保留提醒时间但停止调度，重新打开仅恢复有效未来提醒。首次保存取得真实 ID 后再调度，系统时间/时区变化时重新调度本地时间提醒。
- 删除旧混合通知通道；Android 14+ 首次启动取消旧 Alarm 后重新安排新库提醒。Android 10–13 无需读取旧库，未知 ID 的旧单次广播到达后直接忽略，不再续调。

### 备份

- 使用 `format=grit_rhine`、`formatVersion=1` 的独立格式，版本与 Room schema 分开；Section 嵌套在 Task 下，taskId 由父 Task 推导。
- 校验 ID、归属、颜色、完成日期、时间顺序及连续排序；不解析旧 steps 或 Habit 格式。
- 文件先读取校验，展示 Category/Task/Section 数量；确认后事务替换。校验/写入失败保留现有新库数据。
- 导出使用一致快照，取消选择文件不显示导出成功；导入导出失败可重试。
- 数据备份不包含本机字体等显示设置。Android 系统备份仅包括新数据库及现有 DataStore，排除旧业务库。
- 原始 Habit 不迁移。后续用户提供导出 JSON 后，在应用外转换成新格式再导入。

### 功能删除与构建

- 删除 Habit 领域、UI、仓库、数据库、统计栏目和三个 Habit 小组件，清理依赖注入、receiver/provider、提醒分支与专用资源。
- 删除 AI 分解、TaskPlanner 各平台实现、AI ViewModel、入口、网络代码及 DeepSeek BuildConfig/本地密钥配置读取；保留 Android SDK 配置和仍用于更新检查的网络能力。
- 删除旧 Section 兼容和旧数据库迁移测试，新增新模型/备份测试与仓库事务测试；旧库 schema 不属于新库迁移链。
- 删除整体调色、动态主题、调色板及五档深浅循环，保留字体选择；Task 小组件同样采用固定米色与可读文字颜色。
- 应用名称为 Grit_Rhine，导航为 Task / Setting / Rhine。保留 Android applicationId、代码命名空间与共享资源包，避免更名导致生成资源路径变化。
- 保留工作区原有更新检查和关于页修改；设置页在其基础上删除旧控件。
- JVM/Wasm Demo 更新为新接口，删除 Habit 示例；不新增这些平台的 Rhine 实现。
- 增加 `copyRhineDebugApk` 构建任务，输出 `androidApp/build/outputs/grit_rhine/Grit_Rhine-debug.apk`，不覆盖工作区原有 APK。
