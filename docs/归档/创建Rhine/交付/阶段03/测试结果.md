12 项通过：[原始设备结果](设备测试结果.txt)。本轮实际补跑了前期只编译的 4 项 TaskRepositoryTest。新增 3 项 RhineDetailRepositoryTest，包含：

- 同类别兄弟 Task 的目录、长/空 Section 列、颜色与日期、已完成/隐藏选项仍可浏览；其他 Category 的 Task 不混入；浏览计数不产生业务记录。
- 单 Section 保存后，ID、正文和 Task 长描述保持；Task 列表所用 `getTasksFlow` 读取同一更新结果；Section 全完成不自动完成 Task；Task 完成不改 Section 日期；取消 Section 完成不取消 Task 完成。
- 未来日期、整页 Task 中非法日期及非法 Category 颜色拒绝；整页保存失败不部分删除 Section、修改标题或正文，原数据完整保留。
