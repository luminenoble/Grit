# 阶段 1：全局液态玻璃设计系统

前置：阅读[总览](README.md)，特别是决策 D1（米色体系内引入玻璃）与 D8（降低透明度）。本阶段只建立材质与组件，并改造 Task、Setting、小组件；Rhine 场景内的使用见[阶段 2](02-Rhine界面与动效重构.md)。

## 1. 范围

| 纳入 | 不纳入 |
| --- | --- |
| 材质令牌、`GlassSurface` 等可复用组件、背景采样模糊 | 动态取色、深色主题、整体调色（已按用户决定移除） |

## 2. 材质分层

玻璃分为四档。前三档属于“控件与导航层”；第四档用于内容，只借用玻璃的光学语言，不做半透明。

| 档位 | 用途 | 着色（`GlassTint`） | 背景模糊（API 31+） | 无模糊回退的着色不透明度 | 阴影 |
| --- | --- | --- | --- | --- | --- |
| `Thin` | 浮在内容上的小控件：导航胶囊、悬浮按钮、Rhine 底部工具栏、提示胶囊 | `#F4F0EA` @ 0.72 | 24dp | 0.86 | 近影 1dp @0.06 + 主影 y6/18dp @0.10 |
| `Regular` | 菜单、浮层、滚动后的顶栏、Rhine 搜索/序号浮层 | `#F4F0EA` @ 0.80 | 32dp | 0.90 | 近影 1dp @0.06 + 主影 y10/28dp @0.12 |
| `Thick` | 对话框、底部表单、Rhine 编辑器面板 | `#F2EDE5` @ 0.90 | 40dp（仅窗口内覆盖层） | 0.96 | 近影 1dp @0.08 + 主影 y16/40dp @0.14 |
| `Content` | 任务卡、设置分组行 | `surface` 不透明 | 无 | 1.0 | 近影 1dp @0.05 + 主影 y3/10dp @0.08 |

阴影颜色统一为暖褐 `#5B4B3A`（`spotColor` / `ambientColor`），避免灰黑阴影在米色上发脏。

### 2.1 光学层（每档相同，强度随档位变化）

一个玻璃表面由下到上绘制：

```text
① 采样层  背景内容 → BlurEffect(r) → 按表面形状裁剪          （仅 Standard 模式且 API ≥ 31）
② 着色层  GlassTint，提供可读的底色
③ 光泽层  竖直渐变：顶部 白@0.22 → 35% 高度处透明              （表面上部的镜面光）
④ 内缘光  1dp 描边，线性渐变：左上 白@0.70 → 中段 白@0.10 → 右下 白@0.30
⑤ 外细线  0.5dp `#5B554B`@0.10，使浅色玻璃在米色背景上有边界
⑥ 底部内阴影 1dp `#000000`@0.04，沿下边缘，增加厚度感
```

不只是 `blur()`：即使没有模糊（Android 10–11、降低透明度模式、对话框窗口），②–⑥ 仍然构成完整的玻璃外观。所有渐变和描边在 `drawWithCache` 中按尺寸缓存，使用 `Outline` 直接绘制，避免逐帧分配 `Path`（沿用 3d182aa 的优化）。

### 2.2 交互状态

| 状态 | 表现 |
| --- | --- |
| 按下 | 缩放 0.97（spring：dampingRatio 0.75、stiffness 700），着色 +0.06，内缘光 ×1.3 |
| 选中（导航项、分段、类别） | 表面内嵌一个“透镜”胶囊：`primaryContainer`@0.85 + 光泽层；位置变化用 `fastSpatialSpec` 滑动 |
| 聚焦（键盘/方向键） | 2dp `primary` 外环，偏移 2dp |
| 禁用 | 内容不透明度 0.38（沿用 Rhine `Pending`），表面不变 |
| 强调（主要操作，如悬浮按钮、确认） | “着色玻璃”：着色改为 `primary` `#5B554B`@0.88，内容为 `onPrimary` |
| 危险（删除确认） | 着色玻璃用 `#8C3B32`@0.90，内容白色；不在普通按钮上用红色 |

## 3. 令牌

新增 `shared/ui/src/commonMain/kotlin/com/shub39/grit/shared/ui/theme/LiquidGlass.kt`，并扩展现有 `GritTokens.kt`：

```kotlin
enum class GlassTier { Thin, Regular, Thick, Content }
enum class GlassMode { Standard, Reduced }          // Reduced = 降低透明度（D8）

@Immutable data class GlassSpec(
    val tint: Color, val tintAlpha: Float, val fallbackAlpha: Float,
    val blur: Dp, val sheen: Float, val rimBright: Float, val rimFaint: Float,
    val keyShadow: Dp, val keyShadowY: Dp, val keyShadowAlpha: Float,
)
object GlassTokens { fun spec(tier: GlassTier): GlassSpec }

// GritRadius 新增
val capsule = 50%          // RoundedCornerShape(percent = 50)
val toolbar = 22.dp
val panel = 28.dp          // 等同现有 xxl
// 文字
val glassSecondaryText = Color(0xFF57534B)   // 次要文字，替代 onSurfaceVariant 用在玻璃上
```

`LocalGlassMode` 由 `GritTheme` 根据设置提供。`Reduced` 时所有档位使用回退不透明度且关闭模糊。

新增 `theme/GritMotion.kt`，Rhine 的计时也从这里取值（[阶段 2](02-Rhine界面与动效重构.md#6-计时与缓动) 使用）：

| --- | --- | --- |
| `EaseStandard` | `CubicBezierEasing(0.2, 0, 0, 1)` | 进入、淡入 |
| `EaseExit` | `CubicBezierEasing(0.3, 0, 0.8, 0.15)` | 淡出、收起 |
| `EaseInOutCubic` | `CubicBezierEasing(0.65, 0, 0.35, 1)` | 相机旋转、下落 |

## 4. 可复用组件

新目录 `shared/ui/src/commonMain/kotlin/com/shub39/grit/shared/ui/components/glass/`：

| 组件 | 说明 |
| --- | --- |
| `GlassBackdrop` / `Modifier.glassSource(backdrop)` | 在内容容器上录制 `GraphicsLayer`（`rememberGraphicsLayer()` + `record { drawContent() }`），每帧只回放显示列表，不重复组合 |
| `Modifier.glassSurface(tier, shape, backdrop = null)` | 绘制 2.1 的 ①–⑥。有 `backdrop` 且模式为 Standard、API ≥ 31 时，按自身在根坐标中的位置平移并绘制模糊后的采样层 |
| `GlassSurface(tier, shape) { }` | 组合式外壳，带 `Modifier.shadow(..., spotColor, ambientColor)` |
| `GlassButton` / `GlassIconButton` | 胶囊按钮，最小触控 48dp，含按压、强调、危险变体 |
| `GlassToolbar` | 胶囊工具栏容器，支持分组与分隔细线；Rhine 底部工具栏使用 |
| `GlassDialog`（替换 `GritDialog` 内部实现）/ `GlassAlertDialog` | 签名分别与 `GritDialog` 和 Material3 `AlertDialog` 相同，调用处只换函数名 |
| `GlassBottomSheet`（替换 `GritBottomSheet` 内部实现） | 玻璃画在 sheet 内容中，不画在 `ModalBottomSheet` 的 `modifier` 上（3d182aa 的教训） |
| `GlassSwitch`（`ExpressiveSwitch` 内部实现换成它） | 自绘轨道与滑块；`Modifier.toggleable(role = Role.Switch)` 保留语义；滑块位移用 spring |
| `GlassSlider` | 使用 Material3 `Slider` 的 `thumb` / `track` 插槽：轨道为内凹凹槽（内阴影），滑块为 `Thin` 玻璃圆钮 |
| `GlassSegmented` | 替代成组的 `FilterChip`：胶囊容器 + 滑动透镜，`Role.RadioButton` 语义 |
| `GlassToast` | Rhine 顶部临时信息的胶囊外观（只换外观，计时与位置不变） |

**窗口边界**：`Dialog`、`Popup`、`ModalBottomSheet` 是独立窗口，无法采样主窗口内容，因此这些地方的 `Thick` / `Regular` 不模糊，只用回退不透明度。Rhine 的编辑器、搜索、序号输入会改为主窗口内的覆盖层（阶段 2），可以模糊；它们的背景是场景，模糊有意义。

## 6. Android 小组件策略

### 6.1 已核对的约束

- 小组件为 Glance 1.2，最终渲染为 RemoteViews：没有 `RenderEffect`，没有自定义着色器，也无法读取桌面壁纸，因此**不可能做真实背景模糊**。
- 背景是 `ImageProvider(R.drawable.widget_matte_bg)` 加 `cornerRadius(24.dp)`（只在 Android 12+ 生效，代码已用 `roundedCornerSupported` 区分）；条目是 `widget_matte_item(_done)`。
- `GlanceTheme(ColorProviders(RhineBaseColors, RhineBaseColors))` 固定为浅色，深浅相同。

### 6.2 方案

用 `layer-list` drawable 组合出玻璃的光学层，Kotlin 代码只替换资源引用：

```text
widget_glass_bg.xml（替代 widget_matte_bg）
  ① 着色   solid #EBF4F0EA（不透明度 0.92，可透出少许壁纸）
  ② 光泽   gradient 顶部 #73FFFFFF → 40% 处 #00FFFFFF
  ③ 内缘光 inset 1dp，stroke 1dp #8CFFFFFF
  ④ 外细线 stroke 1dp #1F5B554B
  圆角 24dp（Android 12+ 由 Glance cornerRadius 裁剪；更低版本靠 drawable 圆角）

widget_glass_item.xml / widget_glass_item_done.xml（替代 matte_item）
  ① solid #CCFFFFFF（叠在 ① 之上）  ② 内缘光 1dp #99FFFFFF  ③ 外细线 #1F5B554B
  done：保留现有的较深米色填充 #E3DCCE（原 matte 设计的完成样式），外细线略深
```

- **任意壁纸下可读**：按最差情况（纯黑壁纸）计算，0.92 着色后为 `#DBD8D3`，主文字 `#3C3A36` 对比度约 7.8:1。次要文字（日期、提醒）改用 `#57534B`，保证 ≥ 4.5:1。若实测深色壁纸上透出过多，就把 ① 调到 0.96。
- 不使用位图，资源开销与现在相同；刷新周期、`LazyColumn`、点击动作（打开应用、切换完成、切换范围、刷新）均不变。
- 预览图 `tasks_widget.png` 在第三期用真实截图更新；Android 15+ 的生成式预览 `providePreview` 自动使用新 drawable。
- 回退：Android 10–11 没有 Glance 圆角裁剪，drawable 自带 24dp 圆角，外观一致；启动器缩放小组件时 drawable 按 9-patch 规则拉伸，形状不变。

## 7. 可读性与无障碍

- 对比度（第一期按 WCAG 相对亮度公式计算，不计模糊）：

  | 下层颜色 | 着色 0.62 | 0.70 | 0.78 | 0.86 |
  | --- | --- | --- | --- | --- |
  | Rhine 最暗侧面 `#A69C90`：主墨色 `#100E06` | 12.6 | 13.5 | 14.4 | 15.3 |
  | 同上：`onSurfaceVariant #625F58` | 4.16 | 4.46 | 4.76 | 5.04 |
  | 地面 `#EAE5E1`：`onSurfaceVariant` | 5.42 | 5.46 | 5.51 | 5.53 |

  因此：主文字在任何档位都满足；`onSurfaceVariant` 在 Rhine 场景上需 ≥ 0.78 才达到 4.5:1，所以玻璃上的次要文字一律改用更深的 `glassSecondaryText #57534B`。模糊会把下层颜色与周围的浅色混合，实际对比度高于这个最差估计。
- 禁止在玻璃上使用 `mutedText #8C857A`（对比度 < 3:1）。
- 触控目标 ≥ 48dp（沿用 `HudButton` 依赖 Compose 最小触控扩展的做法，并把新按钮的可见尺寸做到 ≥ 40dp）。
- 语义：所有新组件保留 `Role`、`contentDescription`，开关为 `Role.Switch`，分段为 `Role.RadioButton` 并 `selectableGroup()`。
- 字号缩放：玻璃组件高度随内容增长，不写死文字行高；Rhine 在字号 > 1.35 时仍使用窄屏布局（现有规则）。
- 降低透明度（D8）：全部档位不透明、关闭模糊，光泽与描边保留。

## 8. 性能要求

- 同一屏同时进行背景采样的玻璃表面不超过 3 个（导航胶囊、顶栏、悬浮按钮，或 Rhine 工具栏、提示胶囊、浮层）。
- 采样层只录制一次内容并回放显示列表，不额外触发重组；模糊半径固定（不做动画），避免每帧重建 `RenderEffect`。
- Rhine 阴影质量为“关”或“低”、降低透明度、减少动效任一开启时，Rhine 工具栏关闭模糊。
- 不新增依赖。在阶段 07 的 `RhinePerformanceTest`、debug `RhineMetrics` 基础上增加玻璃开/关对比记录。
