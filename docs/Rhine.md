# Rhine

Rhine 的现行设计，对应 6.2.4（2026-10-27）。只写现在成立的内容；改动 Rhine 的行为、外观或参数时，在同一个提交里更新本文。设计演变与当时的取舍见 [归档](归档/README.md)，那里的内容不代表现状。

代码在 `shared/ui/src/commonMain/kotlin/com/shub39/grit/shared/ui/rhine/`。视觉基准为 [Rhine_reference.png](Rhine_reference.png)。

## 1. 结构

Rhine 是一个锁定横屏、全屏沉浸的块阵列场景，有两层：

| 层 | 一列对应 | 列内的块 | 块上的标题 | 0 号块 | 列的颜色 |
| --- | --- | --- | --- | --- | --- |
| 类别层 | Category | Task | Task 序号与标题 | 编辑 Category、整列排序 | Category 颜色 |
| Section 层 | 同一 Category 下的 Task | Section | Section 序号与标题 | 编辑 Task、整列排序 | Task 颜色 |

- **块**：薄片，像竖放的光盘。每块只有一行标题，写在长侧面（`front`）上沿，插图在它下方；顶面不写字。块上不写父级名称，归属由列颜色、0 号块和工具栏的列名表示。

- **方向**：沿列 U 从右下到左上；跨列 V 横跨相邻斜列。每列的 0 号块在最右下，真实内容从 1 开始编号。
- **三种块**：真实块（对应数据）；范围内占位块（补齐短列，详情模式下点击可尾部新增）；范围外装饰块（只为铺满屏幕，永远不可交互）。
- 序号是 `orderIndex + 1`，与数据库 ID 无关。Rhine 不应用 `hideCompleted`，已完成 Task 保留位置、以小标记区分。

## 2. 浏览与边界

- 类别层：`C` 个 Category，列 `v ∈ 0..C`（列 C 是唯一的“新增 Category”入口）；`M` 为最长列的 Task 数，`u ∈ 0..M+1`（M+1 只留一格新增）。Section 层以兄弟 Task 数和 Section 数代入，规则相同。
- 所有列共享同一个 U 偏移；拖动、惯性、搜索定位、排序时的自动滚动都经过同一个范围约束器。到边界即停，不回弹、不扩展。
- 边界只由数据决定，密度、字号、块尺寸都不能扩大它。
- 静止时只有中心列抬升，并在焦点块处形成单一主峰：`h(u) = base + center + peak·exp(−(u−focusU)²/(2·spread²))`，中心列最低块仍高于其他列。
- 松手后吸附到最近的块和列；手势按初始主方向锁定 U 或 V。

## 3. 模式与操作

右上角切换“预览 / 详情 / 调整”，两层共用当前模式，默认预览。非中心列的块第一次点击只把它移到中心。

| 模式 | 点击中心列 | 长按 |
| --- | --- | --- |
| 预览 | 只定位 | 无 |
| 详情 | 0 号块：编辑父对象；类别层真实 Task：进入 Section 层；Section 层真实块：编辑 Section；范围内占位：尾部新增一个子项；新增列：新增 Category / 兄弟 Task | 无 |
| 调整 | 点按真实块或 0 号块：“移动到第 N 项”（`1..同级数量`） | 真实块沿 U 排序；0 号块沿 V 整列排序；松手一次性提交，取消即还原 |

- **只尾插**：远处占位上新增只追加一个对象（U=99 新增得到第 2 项，不补空数据）。新增父对象后定位到它的 0 号块，不自动打开子项表单。
- **删除后定位**：优先原位置的后继，没有则前项，列空则回到 0 号块；删除当前层所属 Category 时回到类别层。
- **搜索**：只搜 Task 标题（含已完成，不区分大小写，支持中文子串）；选中结果后回到类别层、以预览模式定位到该 Task。
- **离开**：页脚 `TASK ↗` / `SETTING ↗`；系统返回在 Section 层回上一层，在类别层回 Task 页。
- 跨页面一致：Task 页与 Rhine 用同一仓库，按 ID 重新解析位置；全量导入后从首个有效位置开始。

## 4. 界面

- **HUD**：左上品牌块（`Grhinet` / 层级 / 模式）；右上 SEARCH、模式、回到开头（U 归零，保留中心列）；左下沿列读数；右下中心列完成数；页脚数据规模与离开入口。均为直接叠在场景上的文字。
- **底部玻璃工具栏**（`RhineToolbar.kt`）：A 返回（仅 Section 层）、B U 步进与刻度、C V 切换、焦点胶囊（标题与状态）、D 当前模式的主操作与删除。宽屏条件为 `w ≥ 700dp`、`h ≥ 340dp`、字号 ≤ 1.35，否则为可横向滚动的单行工具栏。工具栏不得遮住焦点块，放不下时改为低矮模式，不移动场景锚点。
- **浮层**：搜索、序号输入、Category/Task 编辑器是窗口内覆盖层（能模糊场景）；Section 编辑器与删除确认为玻璃对话框。顶部临时信息为玻璃胶囊，3 秒消失。
- 详情模式下从工具栏删除只弹确认框，不打开编辑器。

## 5. 相机与过渡

投影是手调的斜轴测，不是 3D 引擎（`RhineGeometry.kt`）：

```text
screen = anchor + (wu − camU)·eU + (wv − camV)·eV + z·eZ
eU = (−0.959, −0.282)  eV = (0.875, −0.485)  eZ = (0, −1)  anchor = (0.34W, 0.60H)
```

- 画家序为 u 降序、再 v 降序；每块只画顶面、长侧面（`front`，u0 侧，朝右下）和端面（`cap`，v0 侧）。
- **位姿** `RhinePose`（`RhinePose.kt`）：偏航 ψ、俯仰系数 `kh`/`kz`、缩放、枢轴。恒等位姿必须与上式逐位相同（单元测试覆盖）。偏航只能在 `[0, ψ_E≈47.6°]`，正方向为场景在屏幕上顺时针转（俯视下相机逆时针绕行）；超出范围会露出未绘制的端面并破坏画家序。
- 每帧位姿由起点、终点和进度直接算出，终点直接赋值，不累加。

| 过渡 | 时长 | 内容 |
| --- | --- | --- |
| 进入 Task | 1000 ms | 抬升 0.8 H（0–650）、偏航到 0.5 ψ_E 并放大 1.06（0–700）、场景淡出 450–700、700 换层、淡入 700–1000 |
| 返回 Category | 360 ms | 整屏缩放淡出 180 + 淡入 180 |
| 编辑器进入 | 1500 ms | 抬升 H+12dp（0–550）、偏航 0.8 ψ_E / kh 1.30 / kz 0.96 / 缩放到预览区（550–1150）、背景过渡 1100–1350、面板淡入 1250–1500 |
| 编辑器退出 | 1500 ms | 面板淡出 0–250、背景退回 200–500、下落与回转 500–1500、HUD 淡入 1350–1500；删除时块先溶解 250–600 |
| 减少动效 | 0 | 顺序不变，时长为 0 |

`RhineDirector` 是过渡的唯一所有者（`Idle / NavEnter / NavBack / EditorEnter / Editing / EditorExit`）：过渡中忽略点按；新过渡先取消旧的并递增 epoch；数据被导入替换时中止回 `Idle`；位姿不随进程保存。点按的块不在焦点时，先用 240 ms 平移对准再开始序列。

## 6. 编辑器

- Category / Task 的编辑与新建走 1.5 秒的电影化进出和分屏：左侧是同一张场景画布（抬起的块在编辑位姿），右侧是玻璃面板，内含共享表单 `CategoryUpsertSheet` / `TaskUpsertSheet`。Section 编辑保持普通对话框。
- 抬起的块实时显示草稿的名称、颜色和插图：长侧面上沿为 `00 ✎ 名称`，整块染草稿的颜色。
- **背景**：编辑时其余块从转动、放大的场景交叉淡入为进入前的总览阵列（中性位姿，抽出块的位置空着），玻璃模式下模糊 3 dp 并盖 10% 地面色，哑光模式下不模糊、盖 55%。
- 退出目标：取消或保存已有对象回进入前的视角；保存新建对象时块下落到新对象的槽位；删除后溶解再回转；提交失败留在编辑态并保留草稿。
- 编辑状态随界面保存：图库返回导致 Activity 重建时恢复编辑姿态与草稿；每次打开分配新的会话号，草稿不会串到其他对象。

## 7. 材质

**玻璃模式**的条件：Android 12+（能模糊）、未开启“降低透明度”、阴影质量为“标准”。否则为**哑光模式**。

### 7.1 磨砂玻璃

块的外形、棱角、标题和插图始终清楚，只有隔着玻璃看到的东西是磨砂的。每帧画两层（`RhineScreen.kt`、`RhineRenderer.kt`）：

- **背后层**（`RhinePass.Backdrop`）：地面、阴影、所有块的半透明面（含列颜色）和插图，不画文字，选中块最后画。录进 1/2 尺寸的图层，模糊并提高饱和度（默认 8 dp、×1.35，见第 10 节）。
- **表面层**（`RhinePass.Context` 与 `Selected`，画在单独的图层里）：先画不透明的地面和全部接触阴影，再按画家序逐块用 `BlendMode.DstOut` 挖掉这块的轮廓（三个面合成一条路径），露出背后层，然后画它的表面：列颜色、磨砂白（长侧面为“磨砂白度”，默认 30%；顶面再加 48%，至多 94%；端面为其 45% 并加暖灰）、长侧面自上而下的柔光与底部内阴影、颗粒（64 × 64 噪点平铺，默认 5%）、插图、标题，最后是列颜色加深的细轮廓和亮棱（长侧面与顶面相交处最亮）。块之间的缝隙露出清楚的地面，模糊不会溢出块外。
- **选中块**：有抬起的块时为它，否则为相机所在格。它按清晰度 `sharpness`（相机移动时在 0.6 格内过渡）从 `Context` 移到 `Selected`，画在其他块之上，所以整块和插图完整可见。其余块的插图蒙一层 `10% × (1 − sharpness)` 的白。
- 挖空必须直接画在表面层上，透明度取本次份额；放进子图层会只挖掉子图层。列首前装饰块的透视（7.2 末条）同样如此。
- 编辑器的背景阵列只进背后层，模糊半径随背景进度从设置值过渡到 3 dp，盖 10% 地面色；进入前的场景在表面层淡出。

### 7.2 哑光

- 不透明米色块，整幅清晰，没有模糊和颗粒。侧面与阴影从屏幕中心向四周变浅。
- 焦点 Task 有插图且相机静止时，280 ms 内展开完整插图，同列挡在前面的块变为 30% 不透明的清玻璃（标题保持不透明）。
- 列首之前（u < 0）与 0 号块插图重叠的装饰块以 28% 不透明度绘制，排列不变（两种模式都适用）。

### 7.3 列颜色

- 每列整体染上该列 0 号块的颜色（类别层为 Category 颜色，Section 层为 Task 颜色），块自身的标题颜色不参与。0 号块和真实块全强度，范围内占位块半强度；装饰块、“新建”列和未设颜色的列不染色。
- 颜色均匀铺满整个面。渐变沿块长从左到右、等距色标，与文字渐变同向；长侧面和顶面各带完整渐变，端面取第一色。
- 浓度为显示设置“列颜色浓度”（默认 30%）：玻璃表面取该值，背后层取 1.4 倍（至多 90%），哑光按该值混入米色。

## 8. 文字与颜色

- 每块一行标题，贴在长侧面上沿，文字带高 `标题字号 × 1.6 + 4 dp`，再受该面露出高度限制；放不下时缩小字号。长标题只有聚焦块可滚动（默认关闭），其余截断。焦点块的长侧面有一圈深色描边。
- 沿列间隙决定被前一块挡住后还露出多少：`gapU / slopeU`（恒等位姿 `slopeU ≈ 1.229`）。默认 24 dp 时，峰值后方最窄处约露出 10 dp，放得下 8 sp 的标题。
- 标题颜色**原样显示**，不做任何对比度修正；浅色字的可读性由用户自己决定。类别层用 Task 颜色，Section 层用 Section 自己的颜色，0 号块用父对象的颜色。
- 多色渐变用 `drawText(brush)`，从该行字形的左边界到右边界。默认字色：玻璃为深色，哑光长侧面为浅色；占位与“新建”为弱化色。

## 9. 插图

- **存储**：独立表 `rhine_illustrations`（外键级联到 Category / Task），只保存 `content://` URI 并取持久授权，不复制原图，不进入 JSON 备份。启动时对账释放未引用的授权。
- **入口**：Rhine 编辑器与 Task 页的 Category / Task 表单（系统照片选择器，无存储权限）。Task 页只编辑，不显示插图。
- **显示范围**（`showsIllustration`）：抬起的块、每列的 0 号块（类别层为 Category，Section 层为 Task），以及带条目的真实块（类别层的 Task；Section 没有插图）。有图的块展开整块长侧面，标题在上沿，图在标题带下方；可见面小于 18 × 48 dp 时不画。同列的图按画家序互相遮挡，叠在一起时每块只露出上部，被挡住的部分隔着前面的玻璃磨砂可见；选中块画在最上层，图完整可见。
- **读取与解码**：读取中心列左右各 3 列的列首插图，以及这些列中焦点前后 8 格的 Task 插图。解码档位为长边 384 / 768 / 1280 px：焦点前后 1 格按所需尺寸取档，其余用 384。LRU 缓存上限 48 MB；解码失败记为不可用，30 秒后可重试，编辑器中显示“图片不可用 · 重新选择 / 移除”。
- **裁剪**：显示设置 `illustrationFit`：填充·左上（默认）/ 填充·居中 / 完整显示，从不拉伸。

## 10. 显示设置

本机偏好，JSON 字符串存于 DataStore 键 `rhine_display_v1`（`RhineDisplayConfig.kt`），不进入数据备份；缺省、非法或超出范围的字段各自回退默认值，未知字段忽略。标题字号沿用字段名 `topSp`。

| 密度 | 标准（12 行 × 3 列）；宽松 9 × 2.4、紧凑 16 × 4、自定义 | 行 6–24、列 2–6 |
| 标题字号 | 8 sp | 6–20 |
| 块长 / 深 / 基础高度 | 207 / 8 / 16 dp | 100–360 / 4–16 / 8–48 |
| 中心抬升 / 峰高 / 峰宽 | 24 dp / 70 dp / 4.5 格 | 8–64 / 0–120 / 1–8 |
| 沿列 / 跨列间隙 | 24 / 12 dp | 8–40 / 6–40 |
| 序号显示 | Category、Task、Section 均开 | — |
| 占位显示父名称 | 关 | — |
| 长标题滚动 | 关 | — |
| 减少动效 | 关（系统关闭动画时同样生效） | — |
| 阴影质量 | 标准（低 / 关时为哑光模式） | — |
| 插图裁剪 | 填充·左上 | — |
| 列颜色浓度 | 0.30 | 0–0.7 |
| 背后模糊 / 饱和度 | 8 dp / ×1.35 | 0–16 / 1–1.8 |
| 磨砂白度 / 颗粒 | 0.30 / 0.05 | 0–0.6 / 0–0.16 |

## 11. 性能约束

- 只生成可视窗口（加少量余量）内的块；概览只查摘要和计数，不读正文；查询按窗口变化节流，不逐帧查询或写库。
- 文字测量、面路径有上限缓存；静止时不出帧（场景静止 5 秒渲染 0 帧）。
- 从绘制作用域内录制图层时必须传入独立的 `Density`，否则会无限递归。

## 12. 参数在哪里

| 想调的 | 位置 |
| --- | --- |
| 列颜色浓度、背后模糊与饱和度、磨砂白度、颗粒（用户可调） | `RhineDisplayConfig.kt` 的 `tint`、`frostBlur`、`frostSaturation`、`frost`、`grain`；经 `RhineDisplay.kt` 的 `style()` 进入 `RhineStyle` |
| 背后层尺寸、编辑器背景 | `RhineScreen.kt` 末尾：`FrostScale`、`BackdropBlur`、`GlassBackdropVeil`、`MatteBackdropVeil` |
| 由白度推出的顶面与端面、插图蒙白、亮棱、柔光、哑光配色 | `RhineStyle.kt`；列颜色来源 `RhineSlot.tintColors()` |
| 选中过渡、清玻璃与透视透明度、颗粒图 | `RhineRenderer.kt`：`SharpReach`、`ClearGlassAlpha`、`SeeThroughAlpha`、`rhineGrain` |
| 过渡时长与角度 | `RhinePose.kt`：`RhineMotionSpec` 及各 `*Frame` 函数 |
| 投影基向量与块尺寸推导 | `RhineGeometry.kt`、`RhineDisplay.kt` |
| 插图范围、解码档位、缓存 | `RhineIllustrations.kt`；读取范围在 `RhineScreen.kt` |

## 13. 仍然有效的决定

这些是用户明确定过的，修改前先问：

- Rhine 只做横屏手机，画面以参考图为准。块体为米色或无色玻璃，每列整体染该列 0 号块的颜色（2026-10-27 起）；标题颜色只作用于文字。
- 块是薄片：每块一行标题，写在长侧面上沿，与插图同一面；顶面不写字，块上不写父级名称。块深可选 4–16 dp。
- 只尾插，不生成中间空数据；边界只由数据决定，不能无限滑动。
- 截图、录屏不提交入库。
- 文字颜色原样显示，不加对比度“滤镜”。
- 所有有插图的块都显示插图，而不是隐藏。块的外形始终清楚，只有隔着玻璃看到的后方是磨砂的，不对整块加模糊。
- Section 编辑不走 1.5 秒的电影化进出。
- 插图只存 URI，不复制原图；只在本机有效。
- 列首前的装饰块保持原有抬升，与 0 号块插图重叠时半透明，而不是移开。

## 14. 已知限制

- 磨砂是两层近似：后方的模糊半径固定，不随距离变化；紧贴在块边缘的后方内容会略微透出模糊的光晕。
- 同列有图的块互相叠压，只露出上部条带。
- 光照是二维近似，不随光源或设备姿态变化。
- 未设颜色的列没有颜色线索，块的归属只能看 0 号块和工具栏的列名。
- 照片被删除或授权被撤销后插图不可用；URI 不能随备份迁移到其他设备。
- 渐变方向固定为从左到右。
- 未在实体手机上测过帧率。模拟器上拖动浏览每帧约 133 ms（Debug）、65 ms（Release），为 6.2.1 的测量，6.2.3 的磨砂管线未重新测量。哑光回退的外观未在 Android 10–11 上看过。
