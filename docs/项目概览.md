# 项目概览

Grhinet 的现行结构，对应 6.2.3（2026-10-27）。Rhine 场景单独写在 [Rhine.md](Rhine.md)，构建与发布见 [开发与发布.md](开发与发布.md)。改动这里描述的内容时，在同一个提交里更新本文。

## 1. 应用

基于上游 [Grit](https://github.com/shub39/Grit) 修改的 Android 工作记录应用（GPL-3.0）。显示名 Grhinet，`applicationId` 与代码包名保留 `com.shub39.grit`。

- 底部导航：**Task / Setting / Rhine**。Rhine 页隐藏导航，锁定横屏。
- 已从上游移除且不恢复：Habit、统计栏目、AI 任务分解（DeepSeek）、动态取色与整体调色、深色主题。

| 项目 | 现状 |
| --- | --- |
| 语言 / UI | Kotlin 2.4、Compose Multiplatform 1.11.1、Material3 Expressive |
| 模块 | `:androidApp`（Room、DataStore、Glance 小组件、平台实现）、`:shared:core`（模型与接口）、`:shared:ui`（commonMain UI，含 Rhine）、`:webDemo`（JVM / Wasm 演示桩，需保持可编译） |
| Android | minSdk 29、target / compile 37 |
| 主题 | 固定米色浅色主题 + 暖色液态玻璃（见第 4 节） |

## 2. 数据

以 `Category → Task → Section` 组织，Task 页与 Rhine 共用同一仓库。

| 对象 | 主要字段 |
| --- | --- |
| Category | `name`、`description`、`orderIndex`、`titleColor`、`hideCompleted`（只作用于 Task 列表和小组件）、`createdAt/updatedAt` |
| Task | `categoryId`、`title`、`description`、`orderIndex`、`titleColor`、`isCompleted`（手动）、`isToday`、`reminder`、时间戳 |
| Section | `taskId`、`title`（空则为 `unname`）、`content`、`orderIndex`、`completedOn`（null 为未完成）、`titleColor`、时间戳 |

规则：

- ID 固定，不随排序改变；`orderIndex` 在同一父级内从 0 连续；新增一律尾插；移动和删除在事务内补齐排序。
- Section 完成由 `completedOn` 推导：勾选填当天，可改为过去日期，不能是未来；取消完成清空。同一天允许多条。
- Task 与 Section 的完成互不影响。已完成 Task 不触发提醒，重新打开时只恢复仍在未来的提醒。
- **颜色** `titleColor`：null 为默认；`#RRGGBB` 为纯色；2–5 个以逗号分隔为从左到右的渐变（如 `#C0392B,#1E6FD9`）。仓库写入、备份导入都校验格式。颜色原样显示，不做对比度修正。

**数据库** `grit_rhine_database`，Room，`SCHEMA_VERSION = 3`（`androidApp/.../tasks/data/database/`）：

| 版本 | 变化 |
| --- | --- |
| 1 | `categories`、`tasks`、`sections` 三表，外键级联 |
| 2 | 新增 `rhine_illustrations`（插图 URI，外键级联到 Category / Task），自动迁移 |
| 3 | `sections` 新增可空 `titleColor`，自动迁移 |

上游 Grit 的旧数据库不读取、不迁移、不删除。不支持降级安装。

**备份**：`format = "grit_rhine"`、`formatVersion = 1`（`shared/core/.../settings/backup/RhineBackup.kt`），Section 嵌套在 Task 内。导入先校验（ID、引用、颜色、日期、连续排序）、展示数量，确认后在一个事务内整库替换；失败不改动现有数据。备份不含插图和本机显示设置。旧格式不兼容，旧数据由用户在应用外转换后导入。

## 3. Task 页与 Setting

- Task 页：类别切换、今天视图、任务卡、详情编辑。Section 列表有“调整顺序”切换：默认右侧为编辑图标，调整时为拖动手柄，也可输入目标序号。详情页用一份草稿，保存时整体提交，返回时有未保存提示。
- 颜色选择 `ColorPickerDialog`：纯色 / 渐变（至多 5 色）、色环与亮度、R/G/B 与 HEX 输入、复制粘贴（同时写入应用内与系统剪贴板，粘贴优先读系统剪贴板）。Category、Task、Section 表单共用 `TitleColorRow`。
- 插图行：Category / Task 表单可选图，只在 Rhine 显示。
- Setting：外观（字体、“降低透明度”）、Rhine 显示设置（带实时预览，见 [Rhine.md 第 10 节](Rhine.md#10-显示设置)）、备份、更新内容、关于。

## 4. 液态玻璃

代码：`shared/ui/.../theme/LiquidGlass.kt`、`theme/GritMotion.kt`、`components/glass/GlassComponents.kt`。

| 档位 | 用途 | 着色 | 背景模糊（Android 12+） |
| --- | --- | --- | --- |
| `Thin` | 导航胶囊、悬浮按钮、Rhine 工具栏、提示胶囊 | `#F4F0EA` @ 0.72 | 24 dp |
| `Regular` | 菜单、滚动后的顶栏、Rhine 搜索 / 序号浮层 | `#F4F0EA` @ 0.80 | 32 dp |
| `Thick` | 对话框、底部表单、Rhine 编辑器面板 | `#F2EDE5` @ 0.90 | 40 dp（仅窗口内覆盖层） |
| `Content` | 任务卡、设置分组行 | 不透明 | 无 |

- 一个玻璃面由下到上：模糊采样层 → 着色 → 顶部光泽 → 内缘光 → 外细线 → 底部内阴影。没有模糊时（Android 10–11、降低透明度、独立窗口）其余层仍构成玻璃外观。阴影统一为暖褐 `#5B4B3A`。
- `GlassMode.Reduced`（设置“降低透明度”）：全部不透明、关闭模糊。
- `Dialog`、`Popup`、`ModalBottomSheet` 是独立窗口，采样不到主窗口内容，因此不模糊。底部表单的玻璃要画在 sheet 内容里，不能画在 `ModalBottomSheet` 的 `modifier` 上。
- Task / Setting 的导航胶囊与顶栏不做背景模糊（`Scaffold` 下没有可采样的内容）。
- 选中的类别是浮起的亮色镜片，已完成任务卡沉入深米色 `#E3DCCE`；都不用黑色描边。
- 玻璃上的次要文字用 `#57534B`，不要用 `mutedText #8C857A`（对比度不足）。

## 5. 小组件

Glance 任务小组件（RemoteViews，无法真模糊桌面）。背景和条目是 `layer-list` drawable（`widget_glass_bg`、`widget_glass_item(_done)`）模拟玻璃。

Task 标题按存储的颜色显示，渐变也一样。Glance 的文字不支持渐变画笔，所以标题是嵌入的 `TextView`（`AndroidRemoteViews`，布局 `widget_task_title`），每个字带自己的 `ForegroundColorSpan`：按小组件实际宽度用 `StaticLayout` 排版（最多两行），取每个字的水平中点在最宽一行中的位置，在等距色标间插值（`widgets/WidgetTitleGradient.kt`）。效果与 Task 页横跨标题的渐变一致，只是逐字而非逐像素。
