# 阶段 6：透明玻璃块与文字颜色

日期：2026-10-27。分支 `rhine-task-illustrations`。发布 6.2.1。取代[阶段 5](05-玻璃块与焦点插图.md) 的磨砂侧面与景深模糊；焦点 Task 完整插图（D14）保留。

## 需求

1. 选择文字颜色时有一层“滤镜”，删除它；选色时可输入 RGB；新增渐变色，至多 5 种颜色；每个 Section 也能设置自己的颜色（含渐变），默认黑色；颜色可复制粘贴，便于在应用内迁移。
2. 参考另一个 Rhine 界面的示意图（用户提供，未入库）：块是透明质感。把块改成同样的透明效果；不同插图互相遮挡的问题，只把选中的块清晰显示，其余模糊。

## 决策

| # | 决策 | 结果 |
| --- | --- | --- |
| D17 | “滤镜”指什么 | 源码中所有文字颜色都经过对比度修正：Task 页 `readableTitleColor` 把颜色压暗到 4.5:1，Rhine 的 `readable` / `readableFace` 在两端色之间来回调整。所选颜色从未原样显示。全部移除，颜色按所选原样显示；浅色字的可读性由用户自己决定 |
| D18 | 颜色存储 | 仍是 `titleColor` 字符串：`#RRGGBB` 为纯色，2–5 个以逗号分隔为从左到右的渐变。Category、Task 格式兼容旧数据；Section 新增可空 `titleColor`，空值为默认黑色 |
| D19 | 复制粘贴 | 复制时同时写入应用内剪贴板和系统剪贴板（纯文本，如 `#C0392B,#1E6FD9`）；粘贴优先读系统剪贴板中的颜色文本，否则用应用内最近复制的颜色 |
| D20 | 透明与模糊 | 块的所有面都改为浅色半透明，后方块和插图透出；除选中块外的场景整体模糊，选中块清晰地画在最上层 |

## 文字颜色

| 部分 | 做法 |
| --- | --- |
| 格式与校验 | `titleColorStops`（`shared/core` `TaskSummary.kt`）解析为 1–5 个 RGB；`validateTitleColor` 拒绝其他格式。仓库写入、备份导入、`Section.normalized()` 都校验 |
| 显示 | `AccentColor.kt`：`titleColor`（原样颜色，渐变取第一色）、`titleBrush`、`TextStyle.withTitleColor`。渐变用 `Brush.horizontalGradient`，作用于文字本身；有渐变的 Text 包在自适应宽度的容器里，使渐变跨越字形而不是整行 |
| Rhine | `RhineStyle.titleColors` 原样取色；`drawFaceText` 对多色用 `drawText(brush)`，渐变起止为该行字形的左右边界。透明玻璃上侧面标签默认深色字，哑光侧面仍为浅色字 |
| 小组件 | Glance 不支持渐变画笔，显示第一色 |
| 选色对话框 | `ColorPickerDialog`：纯色/渐变切换、色环与亮度、渐变色标（增删、选中编辑）、R/G/B 与 HEX 输入（有效即应用）、实时示例文字、复制/粘贴、默认/取消/完成。不透明底，避免下层对话框透出影响判断颜色；横屏时色环与输入左右并排，操作按钮固定在底部 |
| 入口 | `TitleColorRow`：Category、Task 表单与 Section 编辑器共用；Rhine 编辑器复用这些表单 |

## 数据

- 数据库 v2 → v3：`sections` 增加可空列 `titleColor`，Room 自动迁移，已有行不变（`schemas/.../3.json`）。
- `SectionSummary` 增加 `titleColor`，Rhine Section 层的块使用 Section 自己的颜色（之前沿用所属 Task 的颜色）。
- 备份格式仍为 `grit_rhine` v1：Section 多一个可选字段，旧备份照常导入。旧版本应用不认识此字段，无法导入新版本导出的备份。

## 透明玻璃与选中清晰

| 部分 | 做法 |
| --- | --- |
| 材质 | `drawGlassBlock`：顶面白色 78%→64%，长侧面由上沿 52% 白渐变到下沿 36% 暖灰，端面暖灰 60%，细折边加白色边缘高光。没有不透明的面，后方的块、文字和插图都会透出 |
| 两次绘制 | `RhinePass.Blurred` 画地面与除选中块以外的全部块，录制一次后分别画进 1/2 图层（模糊 3 dp）和 1/4 图层（模糊 10 dp），以选中块为圆心径向过渡：近处轻、远处重。`RhinePass.Sharp` 只把选中块清晰地画在最上层，前后的块和插图都不会与它交叠 |
| 选中块 | 有抬起的块（编辑器、进入下一层的过渡）时为该块；否则为相机所在格。相机移动时清晰度在 0.6 格内从一个块过渡到下一个（`sharpness`），两次绘制按比例分担，不会闪变 |
| 取消 | 阶段 5 的磨砂源图层（`drawRhineBackdrop`、`frostLayer`）删除：后方内容已经整体模糊，透明面直接透出即可 |
| 回退 | Android 10–11（无模糊）、“降低透明度”、阴影质量低/关：保持原哑光不透明外观，整幅清晰 |

## 验证

- 单元测试：新增颜色格式、Section 颜色备份往返与旧备份兼容、“只有选中块清晰”；原有两项对比度修正测试改为“颜色原样显示”。
- 设备测试：迁移测试增加 v1 → v3 后 Section 颜色为空且可写入渐变。
- 模拟器 `grhinet-visual-api36`（Debug）：
  - Category 选三色渐变、复制；Task 粘贴得到同一渐变；Section 用 HEX 设为红色；保存后 Task 页类别标签、任务卡标题、Section 行与 Rhine 两层（顶面、侧面标签、底部工具栏）均按所选颜色显示，重新打开编辑器颜色仍在。
  - Rhine：选中块清晰、其余模糊；步进后清晰块随之切换；编辑器分屏中抬起的块清晰。
  - 修正：HEX 输入强制补 `#` 时光标跳动导致字符错序，改为 `TextFieldValue` 并在规范化时把光标放到末尾。
  - 修正：关闭选色对话框后，宿主对话框（Section 编辑器）重新获得窗口焦点并把焦点交给第一个输入框，弹出键盘；改为窗口恢复焦点后释放焦点。
  - 修正：未设置颜色时直接点“完成”会写入显式黑色 `#000000`，改为保持默认。
- 帧耗时（模拟器，拖动浏览，`gfxinfo` 中位数）：Debug 133 ms（GPU 6 ms），与 6.1.3 玻璃（113–133 ms）相当；Release 65 ms（GPU 10 ms）。

## 限制

- 颜色不再自动修正：在浅色面上选浅色字会难以辨认。
- 非选中块的标题处于模糊中无法阅读，需选中后看清；底部工具栏始终显示选中项标题。
- 渐变方向固定为从左到右。
