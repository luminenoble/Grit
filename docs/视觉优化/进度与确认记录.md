## 6.1.1 修正（2026-10-18）

1. **选中与完成状态不再使用黑色描边**。选中的类别（含 Today 与 Task 表单中的类别）改为从玻璃托盘上“浮起”的亮色镜片：暖色阴影、边缘高光、半粗体文字；未选中的类别平铺、文字较淡。已完成的任务卡沉入与小组件完成行相同的深米色（`#E3DCCE`），无阴影，标题加删除线并减淡，右侧为橄榄色完成标记。
2. **Rhine 编辑器选图后不再退出**。原因：部分手机的图库以全屏或竖屏打开，返回时 Activity 被重建，编辑器状态只保存在 `remember` 中而丢失。修正：
   - `MainActivity` 自行处理方向与屏幕尺寸变化（`configChanges`），竖屏图库返回横屏不再重建；
   - 编辑器状态（编辑对象位置与 ID、表单草稿、插图草稿）随界面保存，Activity 仍被重建时（夜间模式切换、系统回收）直接回到编辑姿态并恢复草稿，图库返回的图片照常写入草稿，由用户决定保存或取消；
   - 恢复时重新核对对象 ID，位置上的对象已变化则关闭编辑并提示。
3. **草稿名称串到其他对象**。原因：名称输入框的文字是可保存状态，Activity 重建后残留，下一次在同一位置打开编辑器（即使是另一个类别）时被恢复。修正：每次打开编辑器分配新的会话号，编辑器按会话号隔离状态；Task 页表单的草稿也改为完整保存。

验证：模拟器上在图库打开期间强制重建 Activity（系统日志 `wm_relaunch_activity`），选图后编辑器保持打开、名称与图片均在；重建后取消、切换到另一类别再编辑，名称正确；新的保存器有单元测试。
