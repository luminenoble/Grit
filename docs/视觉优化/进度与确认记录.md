### 与设计文档的偏差（均已在代码注释中说明）

1. **Task / Setting 的导航胶囊与顶栏不做背景模糊**：`Scaffold` 让内容停在它们之外，模糊没有可采样的内容；它们使用无模糊的玻璃（着色 + 光泽 + 内缘光）。悬浮按钮浮在列表上，按设计采样列表模糊。
2. **搜索 / 序号浮层只有出现动画**，关闭时立即移除（关闭由外部状态决定）。
3. **新建对象的标签不做 300ms 交叉淡化**：抬升开始时直接切换为草稿名称（“未命名”）。
4. **列首之前（u < 0）的装饰块不再随中心列抬升（新决策 D11，需用户确认）**。原因：0 号块的长侧面原本被前方装饰块遮挡，只露出约 20dp，插图在概览中几乎永远放不下。改动后中心墙从 0 号块开始，0 号块侧面完整露出；其他位置不变。
5. 小组件“已完成”条目保留原有的较深米色填充（设计文档误写为深色描边）；类别选中描边保留已确认的 2dp（设计文档写 1.5dp）。
6. 详情模式下从工具栏删除 Category / Task 时只弹出确认框，不再在背后打开编辑面板；删除语义不变。
7. 点按的块不在焦点时，编辑器入场前相机先用原有的 240ms 平移对准该块，再开始 1.5 秒序列。
