## 维护规则

- 现行文档只写现在成立的内容，不写变更过程。改动行为、外观、数据或流程时，在同一个提交里改对应段落；被推翻的内容直接删除，不留“已作废”。
- 用户明确定过、容易被误改的取舍，写进 [Rhine.md 的“仍然有效的决定”](Rhine.md#13-仍然有效的决定)。
- 变更历史由 git、`CHANGELOG.md` 和 GitHub Release 承担，不另写阶段文档或进度记录。
- 截图、录屏、APK 不入库。
