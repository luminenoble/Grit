## 任务与实现

| 范围 | 实现 | 行为 |
| --- | --- | --- |
| 配置模型 | core/settings/RhineDisplayConfig | 版本化本机配置、范围校验、逐字段回退、未知版本整体默认 |
| Setting入口 | RootPage / SettingsGraph / RhineDisplayPage | 密度/字号、块体、标记/效果三个分类；滑杆避免非法文本输入；左侧同场景预览，窄屏上下排列 |
| 保存与取消 | SettingsAction / State / ViewModel / SettingsDatastore | 本地草稿实时预览；保存单次原子写入；取消不写入；失败提示并允许重试；重置只更新草稿，保存后生效 |
| Android与共享平台 | SettingsDatastoreImpl / RuntimeStubs | Android Preferences DataStore持久化；JVM/Wasm stub使用StateFlow维持相同接口 |
| 几何与字号 | RhineDisplay / Projection / Renderer | 视口按dp计算，sp独立跟随系统fontScale；面不足时字体等比适配单行高度，保持居中、裁剪、省略 |
| 标记 | RhineLabels / Renderer / HUD | Category、Task、Section序号各自切换；0号保留名称和✎，HUD继续说明0号操作；占位父名称默认关闭，装饰无名称 |
| 动态与阴影 | RhineBrowser / Canvas / WindowMode actual | 减少动态时吸附/层级/让位直接完成，拾起保持6dp；关闭浮动与跑马灯，有限边缘滚动继续工作；标准双层/低单层/关闭阴影 |
| 文字颜色 | RhineStyle.readableFace | 原始#RRGGBB不写回；用顶面及侧面渐变的两端底色保证4.5:1可读对比；块体材质不变 |
| 配置与尺寸失效 | RhineScreen / saveable state holder | 清未提交拖动、序号、自动滚动、搜索/选择与层级动画；提交事务不重发；上下层按稳定ID重算；保留父层返回快照 |
| 手机安全区 | rhineSafeDrawingInsets + Android actual | HUD、设置、搜索/序号、Category/Task/Section表单保留刘海及系统栏可能出现的区域；小窗口/大字体采用紧凑HUD，不共享重叠的绝对位置 |
| 测试入口 | RhinePreviewActivity / RhineFixtureModel | 仅独立内存Room与专用rhine06-isolated DataStore；ViewModel跨配置重建保留样例库，模拟生产单例仓库；不读取用户实际数据 |

代码仍复用窗口摘要、计数、RhineBounds、hitTest、两层数据源和事务MoveScope；没有全量载入正文、逐帧写库、摘要upsert、解除restrictStructure/allowDraftChanges或改变备份格式。

## 默认值、范围与兼容

| 配置字段 | 默认 | 有效范围/规则 |
| --- | --- | --- |
| density | Standard | Loose / Standard / Compact / Custom |
| targetRows / targetColumns | 12 / 3 | 6–24 / 2–6，视口目标；宽松9/2.4，紧凑16/4 |
| topSp / sideSp | 8 / 7 | 各6–20sp；系统缩放只用于文字，面高度不足时缩小线框 |
| length / depth | 207 / 18 | 自定义100–360 / 12–64dp |
| base / center / peak | 16 / 24 / 70 | 8–48 / 8–64 / 0–120dp；peak为额外高度 |
| spread | 4.5 | 1–8格 |
| gapU / gapV | 16 / 12 | 8–40 / 6–40dp |
| categoryNumbers / taskNumbers / sectionNumbers | true | 独立开关；Task控制上层内容与下层父列 |
| placeholderNames | false | 仅真实父对象的有效占位有名称；装饰没有父对象 |
| scrollFocusedTitle | false | 显式开启后仅聚焦块面内往返滚动；28dp/s、两端各停1秒 |
| reduceMotion | false | Android任一系统动画scale=0时同样生效 |
| shadow | Standard | Off / Low / Standard |

标准密度在2400×1080/420dpi，即914.286×411.429dp上严格从207/18/16/12dp基线开始。视口目标以此标定，U比例为 `(视口高/411.429)×(12/目标块数)`，V比例为 `(视口宽/914.286)×(3/目标列数)`，推导后按合法尺寸范围限制。高度与峰宽独立。修改长、深或间隙进入Custom；目标输入隐藏并保留，切回预设不覆盖自定义尺寸。

预览按完整窗口的横屏尺寸计算，再等比缩小并裁剪进面板；显示与窗口相交的顶面数量，包含边缘与装饰，不能理解为同时可读的真实内容数量。斜投影、遮挡、尺寸范围限制会使此结果不同于12/3这样的目标；目标不是业务上限，也不要求把既有基线强制改成恰好12个面。

Preferences键只有 `rhine_display_v1`，值为含 `version=1` 的JSON。缺失、损坏JSON、无版本或未知版本整体回默认；未知字段忽略，未知枚举回该字段默认，非法类型及非有限/越界数值回该字段默认。写入也先normalized。此JSON与业务 `grit_rhine` 数据备份完全分离。

## 保留与调整

- Geometry的basis、anchor、默认高/峰宽、材质明暗均保留；标准未恢复旧310dp块长。
- 普通吸附240ms、层级360ms（180+180、1.025倍、上移8dp、最低alpha0.62）、让位240ms与拾起6±3dp/900ms保持。减少动态/系统关闭动画时，上述装饰运动归零或立即完成，拾起保持6dp，边缘48dp及4U/s、0.65V/s不变。
- 窗口计算包含9dp拾起最大高度、阴影的0.45U/0.225V伸出和3格查询余量；排序窗口另有保守抬升余量。边界仍只来自真实目录和计数。
- 长标题默认关闭滚动，遵循后来确认的单行居中省略。与总方案10节早期“默认开启”的差异在本期录屏展示，不重复索取旧确认。
- HUD及表单新增系统栏安全空间，普通画面位置相对阶段05略向安全区内调整；场景Canvas仍全屏、投影和命中不缩进。原因是实际临时系统栏截图发现底部入口被覆盖。Android使用不依赖可见状态的status/navigation bar inset，JVM/Wasm同步提供stub。参考[Android官方inset说明](https://developer.android.com/develop/ui/compose/system/insets)。
