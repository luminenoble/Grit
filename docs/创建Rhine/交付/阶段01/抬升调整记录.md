# 阶段 01：抬升高度翻倍

日期：2026-10-09。按用户要求，只修改默认抬升参数，其他场景参数与功能保持原样。

| 参数 | 修改前 | 修改后 |
| --- | --- | --- |
| 中心列整体抬升 `centerLift` | 14 dp | 28 dp |
| 主峰额外抬升 `peakLift` | 34 dp | 68 dp |
| 基础块高度 `baseHeight` | 24 dp | 24 dp（保持不变） |

修改位置：[RhineGeometry.kt](../../../../shared/ui/src/commonMain/kotlin/com/shub39/grit/shared/ui/rhine/RhineGeometry.kt)。中心主峰总高度由 72 dp 变为 120 dp；翻倍的是抬升量，不包含基础块高度。块尺寸、间隙、峰宽、投影、视角、字体、配色和控件均未修改。
