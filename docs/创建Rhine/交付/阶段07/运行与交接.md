# 阶段07运行与交接

最终包：[Grit_Rhine-stage07-v1.apk](Grit_Rhine-stage07-v1.apk)，Android FOSS Debug / 6.0.7-rhine-stage07-v1 / 6070。Debug与正式应用包名不同，安装不会覆盖正式包。截图、回归及性能样例均使用Debug Activity内存Room和专用 `rhine06-isolated` DataStore，不覆盖业务库和业务偏好。

## 安装和入口

```sh
cp docs/创建Rhine/交付/阶段07/Grit_Rhine-stage07-v1.apk /mnt/d/Rhine-stage07.apk
/mnt/d/professionalTools/AndroidStorage/sdk/platform-tools/adb.exe install -r 'D:\Rhine-stage07.apk'
```

日常入口为底部 Rhine；设置从 Setting → Rhine显示进入。退出Rhine通过TASK ↗、SETTING ↗或类别层Android返回键。正式入口使用真实业务仓库。

隔离复现（已有模拟器 `rhine-p0-api36`，不wipe data；Windows SDK adb）：

```sh
adb.exe shell am start -S -n com.shub39.grit.debug/com.shub39.grit.rhine.RhinePreviewActivity \
  --es dataset large --ef u 50 --ef v 49
adb.exe shell am start -S -n com.shub39.grit.debug/com.shub39.grit.rhine.RhinePreviewActivity \
  --es dataset sections1000 --ef u 1 --ef v 0 --ez detail true
```

large为100类别各100Task；初始Category50/Task50，逻辑U50/V49。sections1000为1类别2Task、Section1000/1；进入Task1第二层从0号开始。实际Task/Rhine互通复现添加 `--ez enableTaskPage true`，此时TASK ↗打开真实TasksPage/TasksViewModel及同一内存仓库；页面顶部“返回隔离 Rhine”返回场景，离开Rhine恢复原方向。普通样例不创建TaskViewModel，生产包没有此选项。

每次 `-S` 重建内存样例；关闭Activity后内存库由ViewModel关闭。测试显示文件独立于用户设置，测试后已保存Standard默认值。不要清空应用数据或替换真实数据库以重跑样例。

[测试结果](测试结果.md)列出Java21构建、64项单元、设备测试和UI回归命令。[性能采集.py](性能采集.py)固定次数采样，原始FrameMetrics、gfxinfo framestats和meminfo保存在logs；统计是实际窗口帧时间，视频编码fps不是性能指标。

python3 docs/创建Rhine/交付/阶段07/性能采集.py after
