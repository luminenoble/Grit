## 交接说明

- RhineFocus.categoryId 在第二层仍表示 Task ID；真实 Category 单独保存在 session.categoryId。新增/删除不得覆盖进入前的父层快照。
- 新对象只在仓库中获得 ID；草稿 id=0、占位与显示序号 0 不落库。createdSnapshot 区分父对象与内容对象；deletedSnapshot 对当前目录查询同位置后继的真实身份。
- 编辑读取完整对象；概览保持窗口摘要与计数，不把摘要转换成完整 Task 保存。直接 Section 表单调用 upsertSection；内嵌 Section 先更新 Task 草稿，两者不可混淆。
- restrictStructure 保持 Rhine 排序禁用；allowDraftChanges 独立控制内嵌 Section 增删。新父 Task 的 Section 增删关闭，保存后下一次操作才创建 Section。
- RhineSession.saver 同时识别阶段 03 的 mode-first 列表和本阶段 generation-first 列表；旧会话升级可读取，新保存统一带 token，单元测试覆盖两种格式。
- dataGeneration 是仓库生命周期中的可重放状态。Android 仓库初始化也生成新的 token，因此进程重建保守地丢弃旧视角；不会把导入前缓存恢复到复用 ID 的对象。普通重命名/移动/完成不改变 token。
- 保存后定位等待最多 5 秒；若提交成功但目标已被外部删除/移动导致不能解析，关闭旧草稿并提示重新选择，避免把已提交动作当失败而重复创建。提交前后检查 generation，导入失效后不让旧定位覆盖新起点。
- 保留 240ms 浏览吸附与 360ms 层级过渡（180+180ms、1.025 倍、上移 8dp、最低 alpha 0.62）。RhineGeometry/RhineStyle 与前期哈希一致。
- 未开放 SEARCH、ADJUST、拖动排序或目标序号排序；未开展阶段 06 手机字号适配、阶段 07 性能专项。
