## 任务与实现

| 本期任务 | 实现位置 | 状态与说明 |
| --- | --- | --- |
| 真实只读数据 | `RhineDataSource.kt`、TaskRepo、TasksDao、TasksRepository | 正常 Rhine 入口注入现有仓库。类别/计数流用于目录和边界，只查询可见类别的 Task 摘要，不读取 Task/Section 正文；包含已完成 Task，不采用今天或 hideCompleted 筛选 |
| 有限边界与共享偏移 | `RhineNavigation.kt` 的 RhineBounds | 所有入口共用 clamp；C=0 时 U=V=0；有类别时 U=0..M+1、V=0..C；A=100 可到 101。占位/装饰均为场景值，不生成数据库对象 |
| 手势与相机 | `RhineGestureController`、`RhineMotion`、`RhineBrowser` | 逆投影分解 U/V，以物理距离锁轴；惯性衰减、边界截停、整数吸附；手势开始中断旧动画，多指/取消终止当前手势 |
| 动态起伏 | `RhineScene.kt` | U 的峰心连续跟随相机；V 在相邻两列间 smoothstep 交接抬升，静止只有一列起伏。没有修改基线峰高、峰宽或抬升参数 |
| HUD | `RhineScreen.kt` | 连接 U 步进、V 切换、回到开头（保留中心类别）。HUD 是 Canvas 之上的独立命中分支，点按钮不会同时拖动场景。实时读数、最多 31 个刻度；DONE 来自全列计数，不误用窗口内完成数 |
| 焦点身份与尺寸变化 | `RhineFocus`、`RhineBrowser` | 保存 Category/Task ID 和逻辑坐标；单个焦点摘要订阅跟随已保存对象位置变化。尺寸变化重建投影/窗口，不从像素重算焦点；修复首次尺寸测量提前将待加载焦点归零的问题 |
| 可见窗口 | `RhineProjection.visibleSlots`、`queryWindow`、`RhineDataSource.window` | 复用地面/最大高度反投影，加 2 格阴影余量；U 按 8 格、V 按 2 列量化并有限预读；相同窗口不重启查询。单页最多 500 项，订阅替换即释放旧窗口；绘制前剔除面和阴影都在屏外的块 |
| 遮挡命中 | `layoutScene`、`RhineLayout.hitTest` | 复用实际绘制次序，包围盒预筛再查顶面/侧面/端面，最前面的块胜出。装饰块仍参与遮挡，随后拒绝操作，避免穿透点击后面的真实块；按下时固定命中候选 |
| 测试入口 | `androidApp/src/debug/.../RhinePreviewActivity.kt` | 仅 debug 注册，独立内存 Room 库、确定性数据集、同一组 DAO/摘要适配。空库先初始化 schema，不插入占位记录。正式入口没有 SAMPLE 切换 |
| 生命周期 | `rememberRhineInput` | STARTED 时订阅；后台/离开取消流与动画；静止无无限动画，文本测量缓存上限 128 |

关键代码目录：[Rhine](../../../../shared/ui/src/commonMain/kotlin/com/shub39/grit/shared/ui/rhine/)。

## 视觉与动态参数

`RhineGeometry.kt`、`RhineStyle.kt` 与开始前逐字节一致，见[基线校验](视觉参数基线.sha256)。沿用现有代码：长 207dp、深 18dp，间隙 U=16dp / V=12dp；基础高 16dp、中心抬升 24dp、峰值额外 70dp（最高 110dp）、峰宽 4.5 格、峰心在 focusU；原投影基向量、锚点及 v3 明暗全部保留。阶段 01 旧文字记录中的 310dp 不覆盖当前已确认代码中的 207dp。

| 本期运动参数 | 值 |
| --- | --- |
| 触发阈值 | Compose 平台 touchSlop |
| 锁轴 | 逆投影后的物理世界距离，首次超过阈值后锁定到松手 |
| U / V 最大初速 | 65 格/秒、5 列/秒 |
| 惯性衰减 | 指数系数 4.5/秒；到边界立即清零对应速度 |
| 惯性结束阈值 | U≤0.35 格/秒且 V≤0.05 列/秒 |
| 吸附、HUD 定位时长 | 240ms，FastOutSlowIn；同位置不启动动画 |
| 中心列滞后 | 离原中心超过 0.60 列后切换 HUD 身份 |
| 切列高度 | 相邻列 smoothstep 权重；静止一列权重为 1，其余为 0 |

截图检查时发现长列贴面文字可穿过右侧 HUD 字形，增加了仅在焦点区文字周围的 1.5dp 米色细描边，未新增卡片、整块遮罩或修改块体材质。此可读性处理随本期 v1 截图于 2026-10-10 获得用户确认。

### 安装与复现

使用归档 APK，先复制到 Windows `D:\Rhine-stage02.apk`，再执行：

```sh
/mnt/d/professionalTools/AndroidStorage/sdk/platform-tools/adb.exe install -r 'D:\Rhine-stage02.apk'
```

正常使用从应用的 Task / Setting 导航进入 Rhine，读取原仓库。复现测试数据只启动 debug 专用入口：

```sh
/mnt/d/professionalTools/AndroidStorage/sdk/platform-tools/adb.exe shell am start -S \
  -n com.shub39.grit.debug/com.shub39.grit.rhine.RhinePreviewActivity \
  --es dataset uneven --ef u 99 --ef v 0
```

`dataset` 支持 `normal`、`uneven`、`empty`、`one-empty`。可按[采集脚本](采集证据.py)复现所有截图与录屏；内存库随测试 Activity 关闭释放，不打开用户数据库。录屏蓝色圆环需额外 `--ez traceTouch true`，默认关闭。

## 交接说明

- 后续定位统一调用 `RhineBrowser.animateTo` / `move` 和 `RhineBounds`；不要为短列建立独立 U，不以绘制数量扩展边界。
- `RhineLayout.hitTest` 返回最前方 RhineBlock，`slot` 含 u/v、kind、column/item 稳定 ID。先检查 Decoration，再处理不同模式；不要先过滤装饰块再命中。
- `RhineDataSource` 只含读取方法。下一阶段需要的写入继续走现有仓库，保存完成后更新真实计数并按 ID 定位。
- 可见摘要在量化窗口变化时取消旧订阅；类别元数据和计数是全目录 O(C)，Task 摘要与面数据随窗口规模变化。不要把全 Task 正文流接入概览。
- `RhineFocus` 保存稳定身份；尺寸变化和后台恢复复算投影/边界。跨层返回快照、删除后的继任焦点、导入后快照失效和过程恢复的完整策略仍由阶段 03/04 完成。
- 帧率尚未达到 60Hz 目标；需要后续在指定真机/Release 构建中分析和调优。不能据模拟器 Debug 录屏承诺流畅性能。
- 未执行物理手机、系统减少动画/高字号等阶段 06 适配、10000 Task 长时间内存压测、完整旧业务回归、全仓 Spotless。后续阶段范围没有提前实现或验收。
