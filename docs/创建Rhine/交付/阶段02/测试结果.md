实施 2026-10-09，环境重启后的最终复验与采集 2026-10-10。结果仅表示技术检查，不表示用户视觉确认或阶段 03 授权。

## 构建

Java 21：`~/jdk-21`。开始前运行 `:shared:ui:clean :androidApp:clean`。Spotless 按用户说明跳过，未改变项目格式规则。

环境重启后，Kotlin 守护进程连接阻塞；线程栈定位到 `KotlinCompilerClient` 的 RMI 连接，停止本轮进程后改为进程内编译，无需改动源码或项目构建配置。

最终命令：

```sh
JAVA_HOME=$HOME/jdk-21 PATH=$HOME/jdk-21/bin:$PATH ./gradlew \
  --max-workers=2 -Pkotlin.compiler.execution.strategy=in-process \
  :shared:ui:compileKotlinJvm :shared:ui:compileKotlinWasmJs \
  :webDemo:compileKotlinJvm :webDemo:compileKotlinWasmJs \
  :androidApp:testFossDebugUnitTest :androidApp:copyRhineDebugApk \
  :androidApp:assembleFossDebugAndroidTest -x spotlessCheck -x spotlessApply
```

最终结果：上述检查通过（`BUILD SUCCESSFUL`），见[完整构建结果](构建结果.txt)。最后两处 HUD 文案调整后，再次通过共享 JVM/Wasm、Android 构建及单元测试，见 [HUD 收尾构建结果](HUD收尾构建结果.txt)；debug 触摸标记接入后的最终 APK 与单元测试也通过，见[触摸标记构建结果](触摸标记构建结果.txt)。APK 的精确哈希及归档名见 [APK-SHA256.txt](APK-SHA256.txt)。

## Android 设备测试

AVD `rhine-p0-api36`，Android 16/API 36。测试 APK 同样先复制到 D:\ 后安装。

```sh
adb.exe shell am instrument -w \
  -e class com.shub39.grit.RhineBrowseRepositoryTest,com.shub39.grit.RhineTextLayoutTest \
  com.shub39.grit.debug.test/androidx.test.runner.AndroidJUnitRunner
```

5 项全部通过，原始结果见 [设备测试结果](设备测试结果.txt)。测试包含：

- 空内存库初始化 schema 后，并发类别/计数只读流可启动，仍为零条业务记录。
- 新建的隔离磁盘库在没有插入记录前读取类别/计数；测试完成关闭并移除专用临时库。
- 100/1/1 内存库查询 U=99 与重复窗口浏览，数据库计数不变；hideCompleted=true 的类别仍包含已完成 Task，完成计数正确。
- 两项贴面文字排版测试：中英文居中、长标题单行省略。

首次 C=0 模拟器采集发现 Room 内存库尚未初始化 schema 即启动并发订阅，触发 `no such table: categories`。debug 数据入口现先开启空写事务初始化 schema，再开始查询，没有用虚假类别或任务填充空库。

## 性能观察

原始 `*-gfx.txt` 是对应录屏期间 reset 后采样的 `dumpsys gfxinfo`。设备为 60Hz 模拟器、Debug 构建、Windows Hypervisor Platform、NVIDIA RTX 4060 Laptop GPU OpenGL ES Translator；窗口 2400×1080，420dpi。

录屏和蓝色触摸标记会增加开销；尾部样本量小，且包含触摸标记更新，不能作为长时间吞吐量评估。`screenrecord --time-limit 12` 是最长录制时间，静止场景不持续产出新画面，所以编码媒体到最后变化帧约 5–7 秒；平均编码帧率不是屏幕实际刷新率。元数据见 [录屏元数据](录屏元数据.json)。

观察到 U/V 运动有明显跳帧，60Hz 流畅性目标未达到。功能检查通过：U 波峰随位置交接、V 结束后只留中心列抬升、无持续抖动；尾部在触摸标记继续外移时保持 101。真机/Release 性能分析与优化留待后续性能阶段，不能将本次模拟器运行记为性能验收通过。
