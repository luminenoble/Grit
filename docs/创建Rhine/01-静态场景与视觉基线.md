# 阶段 01：静态场景与视觉基线

前置：阅读[执行总览](README.md)及总方案，现有数据架构可编译。无需重新设计业务数据。

## 目标与任务

交付实际可运行、**锁定横屏**的 Rhine 静态场景，画面与 [Rhine_reference.png](../Rhine_reference.png) 一致。用户确认后，后续阶段沿用该视觉基线。规格见总方案 [5.2](../修改文档.md#52-横屏界面控件) 与 [8.6](../修改文档.md#86-横屏版式与参考图对照)。

1. Rhine 页面锁定横屏（进入时切换为 sensorLandscape，离开时恢复原方向），全屏沉浸，隐藏底部三项导航；Task / Setting 页面不受影响。离开 Rhine 使用页脚 `TASK ↗`、`SETTING ↗` 或系统返回键。
2. 以 Compose 自定义绘制建立统一投影：U 从右下到左上（屏幕约 17°），块长边沿 V 向右上约 29°，竖直面竖直。按参考图标定细长板条比例、窄缝和每列可见 10–14 块的密度。
3. 绘制块体顶面、两可见侧面、细微高光、缝影和柔和阴影，端面带小圆形标记；建立面级遮挡次序和裁剪。屏幕四边以默认米色装饰块补满。配色从参考图取色表起步。
4. 建立可复用场景输入：层级、父对象标签、内容摘要、0 号/真实/占位/装饰块类型、焦点及几何参数。隔离投影、绘制和业务适配。
5. 中心列位于画面左中部，静态高度轮廓抬成高墙：一个主峰、两侧降低、最低处仍高于其他列；其他列齐平。动态交接留阶段 02。
6. 全部块的顶面显示 Task 序号和标题，侧面显示 Category 序号与名称（取消此前竖屏版“主峰后方只显示顶部文字”的规则）。文字贴面、单行居中、过长省略并裁剪；颜色独立，未设置用深灰，保留米色块体。
7. 按 8.6 的 HUD 版式绘制左上品牌块、右上控件行、右侧焦点信息区与细线、左下沿列读数、U 步进刻度、V 切换、右下状态和页脚。标明本期哪些控件可用、哪些功能尚未接入。
8. 提供隔离的开发预览样例：标准场景、长中文标题/不同文字颜色、0 号与占位块。正式数据不因预览而被清空或插入测试记录。

本期交付静态绘制和结构基础，后续浏览、真实编辑、排序和显示设置由各阶段接入。样例预览入口与正式数据入口的关系写清楚，便于阶段 02 替换数据来源。竖屏版的几何、HUD 和截图作废，不作为本期依据；可复用的投影、命中、遮挡、文字排版与颜色可读性代码继续沿用。

## 交付物

- 可运行的场景代码与投影/几何/样式模块，默认几何参数集中定义；横屏锁定与沉浸逻辑。
- 可安装 Debug APK 或可运行的 Android 预览构建。
- `交付/阶段01/实现记录.md`：数据样例来源、默认参数、模块接口、构建结果、后续接入点。
- 横屏截图至少三张：`13-landscape-default.png`、`14-landscape-long-title-color.png`、`15-landscape-zero-and-placeholders.png`，按总览记录环境和参数。编号接在既有竖屏截图之后，旧图保留为历史。
- 对比图 `16-reference-overlay.png`：默认场景截图缩放到参考图尺寸后半透明叠加，另附左右并排图；原始截图一并保留。
- 投影方向、几何、遮挡/裁剪和横屏尺寸下全屏覆盖的测试或可复现检查；记录实际检查方式。

## 验收

- Rhine 进入后始终横屏，不出现底部导航；离开后 Task / Setting 方向恢复正常。
- 与参考图叠图时，块长边与列方向角度、板条比例、中心墙位置与高度、列数和 HUD 各区位置一致；差异逐项列出。
- 中心列可辨识，且不是所有列一起起伏；除正常块缝外，场景四边没有因数据少而留下的空白。
- 文字确实位于面内；长标题不穿越边缘，不遮住其他块的文字；浅色选择显示为可读的颜色。
- HUD 避开刘海/挖孔和系统手势区，不遮挡中心墙和焦点块。
- agent 查看实际截图后解决明显缺陷，交付可审阅版本。

## 需要用户确认的核心问题

结合横屏截图与叠图，只询问效果取舍：

1. 块体比例、厚度、中心墙高度和间隙与参考图是否足够接近，哪里需要调整？
2. 米色、高光、缝影和阴影是否接近参考图，是否有过亮、过暗或过重的位置？
3. 贴面文字是否清楚，HUD 各区位置和字号是否与参考图一致、是否遮挡主要场景？

这是重点视觉确认点。收到修改意见后在本阶段改好并提供新版截图；按总览处理明确授权与尚未确认的情况。
